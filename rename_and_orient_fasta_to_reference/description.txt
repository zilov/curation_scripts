# Rename and Orient Chromosomes to Reference

## Цель
Скрипт для переименования хромосом в FASTA файле и изменения их ориентации 
на основе выравнивания на референсный геном (PAF формат).

## Входные данные
1. **FASTA файл** — геном с хромосомами вида SUPER_N (может быть gzip)
2. **PAF файл** — выравнивание генома на референс (FastGA, minimap2 и т.д.)

## Выходные данные
1. **FASTA файл** — с переименованными хромосомами и исправленной ориентацией
2. **Chromosome list** (CSV) — маппинг старых имён на новые + флаг (yes/no для unloc)
3. **Mapping summary** (TSV) — детальная таблица маппинга с покрытием и strand статистикой

## Алгоритм

### 1. Парсинг PAF
- Читаем PAF файл
- Фильтруем: оставляем только записи где query = SUPER_* и target = chr_*
- Группируем выравнивания по query хромосоме

### 2. Определение соответствия хромосом
Для каждой SUPER_X:
- Суммируем длины выравниваний на каждую chr_N
- Выбираем chr_N с максимальной суммой
- Проверяем покрытие: сумма_выравниваний / длина_SUPER_X >= 50%
- Если покрытие < 50% — хромосома остаётся без изменений

### 3. Определение ориентации
Для каждой пары SUPER_X → chr_N:
- Суммируем длины выравниваний со strand "+"
- Суммируем длины выравниваний со strand "-"
- Если "-" > "+" — нужен reverse complement

### 4. Обработка конфликтов и особых случаев

#### Секс-хромосомы (W, Z, Z1, Z2, X, Y и т.д.)
Определяются по нечисловому суффиксу в имени (SUPER_W, SUPER_Z1...)

**Случай A: Аутосома маппится на секс-хромосому референса**
- SUPER_5 → chr_W (референс)
- Результат: SUPER_5 переименовывается в SUPER_(max_autosome+1)
- Пример: если в референсе 20 аутосом, то SUPER_5 → SUPER_21

**Случай B: Секс-хромосома маппится на аутосому референса**
- SUPER_W → chr_5 (референс)
- Результат: SUPER_W остаётся SUPER_W
- Номер 5 пропускается — ни одна хромосома не получит имя SUPER_5

#### Конфликты маппинга
- Если несколько хромосом претендуют на один номер — побеждает та, у которой больше суммарная длина выравниваний
- Проигравшая хромосома получает следующий свободный номер

#### Unlocalized контиги (SUPER_N_unloc_M)
- Мелкие контиги известной хромосомной принадлежности
- Формат имени: SUPER_N_unloc_M (где N — номер родительской хромосомы, M — порядковый номер)
- **Не используют маппинг** — привязка к хромосоме известна из имени
- Ориентация наследуется от родительской хромосомы (если SUPER_5 нужен RC, то и SUPER_5_unloc_1 тоже)
- В chromosome list имеют флаг `no`

### 5. Формирование итогового порядка
1. Аутосомы по порядку номеров (1, 2, 3, ... включая переназначенные max+N)
2. Секс-хромосомы в алфавитном порядке (W, X, Y, Z, Z1, Z2...)

**Важно:** Все хромосомы из входного FASTA должны присутствовать в выходных файлах.
Хромосомы без хорошего маппинга (покрытие < 50%) сохраняют оригинальное имя и ориентацию.

### 6. Генерация выходных файлов

**FASTA:**
- Переименовать последовательности согласно маппингу
- Применить reverse complement где нужно
- Формат имени: SUPER_N (где N — число или буква для секс-хромосом)

**Chromosome list (CSV):**
```
SUPER_1,1,yes
SUPER_2,2,yes
SUPER_2_unloc_1,2,no
...
SUPER_W,W,yes
```

**Mapping summary (TSV):**
Детальная таблица маппинга для диагностики и анализа.
```
query	target	query_length	alignment_length	coverage	plus_strand	minus_strand	needs_reverse_complement
SUPER_1	chr_13	22428360	21929021	0.9777	21401862	527159	no
SUPER_W	chr_19	35849114	20872677	0.5822	20331709	540968	no
...
```

## Параметры скрипта
- `--fasta` — входной FASTA файл
- `--paf` — PAF файл с выравниванием
- `--output` — префикс для выходных файлов
- `--min-coverage` — минимальное покрытие для переименования (default: 0.5)
